# SpringBoot+Vue3 开发 OA 办公系统源码

这套 SpringBoot+Vue3 开发的 OA 办公系统源码，是面向中小企业数字化协同办公的解决方案，采用前后端分离架构，代码规范清晰，支持二次开发，能够覆盖企业内部绝大多数办公管理场景，助力企业实现无纸化办公，降低内部沟通成本。后端基于 SpringBoot 框架开发，配置简洁，接口稳定高效，可轻松对接单点登录、消息推送、文件存储、短信通知等第三方服务。前端使用 Vue3 搭配 Element Plus 组件库，页面交互流畅，界面现代简洁，适配电脑浏览器访问。数据库选用 MySQL，结合 Redis 缓存提升并发性能，满足多人同时在线办公的业务需求。

系统涵盖组织架构、人事管理、可视化流程审批、公文公告、日程计划、文档中心、固定资产管理等核心模块。组织架构模块可维护企业部门、岗位、员工信息，支持精细化多角色权限管控，针对不同岗位分配菜单访问与操作权限。流程审批是 OA 核心能力，支持拖拽式可视化工作流设计，快速搭建请假、报销、采购、用印等审批单据，支持多级审批、会签、或签，审批消息自动推送，审批进度实时可查，替代传统纸质单据，提升审批效率。通知公告用于对内发布各类通知，可设置可见范围，统计已读未读状态。日程模块支持个人日程与团队共享日程，方便员工协同规划工作。文档中心可分类存放制度、合同、方案等资料，设置文档访问权限，支持在线预览与下载，搭建企业内部知识库。资产管理实现办公用品、设备的登记、领用、归还、报废全生命周期管理。后台数据看板直观展示待办任务、审批数量、员工活跃度等指标，便于管理者掌握企业办公运转情况。

整套源码完整交付，无代码加密，附带部署文档，开发人员可以结合企业业务需求定制修改，调整页面样式、流程规则，新增业务模块。系统支持私有化部署，可部署于企业本地服务器或云服务器，保障企业内部数据自主可控。适合中小微企业、分支机构搭建内部协同办公平台。
